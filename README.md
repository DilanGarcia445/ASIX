# ASIX

## Estructura del repositori

```text
/
├── README.md
├── documentacio/
├── recursos/
├── gestio/
└── bitacora/
```

- **README.md**: Fitxer principal amb el nom del grup, integrants i enllaços.
- **documentacio/**: Document del projecte i fitxers relacionats.
- **recursos/**: Scripts, imatges, configuracions de routers/switches, etc.
- **gestio/**: Enllaç o planificació de Trello / tauler de tasques.
- **bitacora/**: Registre de seguiment del projecte.
